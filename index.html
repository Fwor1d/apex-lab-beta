Три источника — ясные границы

Телеметрия содержит записанные сигналы. JSON сообщает заявленное происхождение, но не подтверждает подлинность базы. Тренажёр использует образовательную модель. Эти данные не смешиваются автоматически.

Работа без сети

Главная страница, тренажёр и просмотр отчётов имеют отдельные лёгкие кеши. Подготовьте нужный раздел заранее. Для анализа native DuckDB есть отдельный тяжёлый пакет; он не скачивается при просмотре отчёта.
