# Пространственные контракты — публичная выдержка

Исходный аудит содержит частные метрики и остаётся локальным. Здесь сохранены численные пороги допуска и ограничения, без записанных координат, результатов кругов и агрегатов заездов. В unified Phase 1 реальный spatial source к UI не подключён.

position-source — отдельный readonly адаптер; неизвестные единицы, частоты и rowid запрещают угадывание привязки. Географическая регистрация и native local path — разные допуски. position-mapping использует rigid rotation/translation, scale=1; holdout residuals сами по себе не доказывают CRS. Требуются независимые reviewed anchors/layout/uncertainty. JSON flags не являются разрешением.

Версионированная политика 1.0.0 требует одновременно: подтверждённые CRS/layout; известная неопределённость геометрии 0–5 м; ≥3 разных неколлинеарных независимых ориентиров с конечными координатами в обеих системах (площадь ≥100 м²); anchor max ≤25 м; holdout RMS≤5/P95≤10/max≤25 и all max≤25; согласие обхода≥95%, отсутствие больших скачков; конечное отношение относительного пути к интегралу GPS Speed в пределах 1%. Пороги — консервативные исследовательские guards, не статистический доверительный интервал и не гарантия точности для любых данных.

### Политика локальной пригодности 1.0.0

- ≤50000 точек; ≥3 конечных координат; конечное строго возрастающее время.
- Соединять только соседние исходные точки при dt≤0,15 с, конечных неотрицательных скоростях и |геометрический шаг − трапециевидный интеграл GPS Speed|≤1,5 м + 25% интеграла. Это guard выбросов, не доверительный интервал и не оценка ошибки GPS.
- Любой скачок блокирует показ этого пути. Пропуски разрывают линию; если доля разорванных связей>5%, показ блокируется. Не исправлять/сглаживать точки.
- Интеграл движения≥10 м и отношение длины к интегралу в пределах1±5%; stationary точки сохраняются, но неподвижный набор не доказывает масштаб.
- A/B только из одной записи/контекста/класса данных, по прежнему фильтру eligible/pit=false; общий frame/origin, без скачков, симметричный bounded NN median≤15/P95≤40 м. Это консервативная проверка локальной совместимости, не независимая проверка CRS. Межфайловые преобразования не выполняются.
- Точки связываются с относительным временем по тем же Lap boundaries/startDerivedFromLapTime, что и importer. Каналы берутся из нормализованного профиля на ближайшем clock sample≤0,011 с. Неизвестные каналы остаются null. Координатная частота10Гц и inherited clock assumption≤0,1с доступны в provenance; это не statistical confidence interval.
- На общем дистанционном курсоре маркер — ближайшая исходная координата по времени A/B, допуск≤0,051с; вне допуска его нет. Покадровые кнопки идут по исходному времени A с шагом0,1с; B сопоставлен по дистанции, не по общему elapsed time. Разрывы Lap Dist не превращаются в пространственную интерполяцию; плато отключает replay.
- Ширина экранной линии и круглый маркер символические. Производная GPS Speed — конечная разность между соседними измерениями, не реконструкция силы/сцепления или автомобиля.

Если distance comparison не построен, локальный путь всё равно показывается по исходным координатам. Дистанционное воспроизведение/дельта отключены; цвет Δt остаётся без значения. Наличие пригодного пути не исправляет неподходящий Lap Dist. Повторные A/B source snapshots сбрасываются до проверки новой пары, чтобы при отказе сравнения не оставался старый измеренный путь.
