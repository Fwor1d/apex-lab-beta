Разберите свой круг

Откройте запись LMU и сравните её с вашим более быстрым кругом. Файл читается на этом устройстве, без отправки в сеть.

Анализ на Windows Chrome / Edge. На iPhone удобнее открыть готовый отчёт; импорт больших баз необязателен.

Выберите исходный файл через системное окно. ZIP нужно распаковать заранее.

Ваша запись

Один исходный файл содержит одну сессию. Для другой сессии выберите её файл; данные не объединяются.

Происхождение и ограничения

    Угол колёс, интервенции ABS/TC и координатная система не подтверждены. Карта и диагнозы инцидентов отключены. Номера поворотов не требуются для сравнения по дистанции.

    Исходные события Lap и рабочая проверка качества

    Сравнение по дистанции

    Один и тот же круг A/B — отдельный просмотр. Пит-переезды и неполные записи доступны для просмотра, но не для сравнения времени.

        Производительность и хранение
        
      
          Обработка — в Worker. OPFS, IndexedDB и синхронизация не используются.
          После импорта DuckDB и его файловый дескриптор закрываются;
          нормированные данные остаются в оперативной памяти до очистки или
          закрытия вкладки.
        
      
        
      Измерения появятся после открытия записи.
      
        
        
      
          Лёгкий кеш содержит интерфейс, тренажёр и просмотр отчётов.
          Native-анализ готовится отдельно и загружает только выбранный пакет
          Wasm. Личные файлы не сохраняются.
